# مه‌گلد — توسعه مستقل
پروژه مستقل React + Vite برای توسعه و پیش‌نمایش فروشگاه مه‌گلد؛ جدا از Lovable و بدون انتشار خودکار.

## اجرا
1. Node.js نسخه 20 یا بالاتر نصب باشد.
2. `npm install`
3. در صورت نیاز، `.env.example` را به `.env.local` کپی و مقادیر Supabase را وارد کنید.
4. `npm run dev`

## ایمنی
- این نسخه هیچ سفارش یا تغییری در دیتابیس ثبت نمی‌کند.
- کلید `service_role` هرگز نباید در مرورگر قرار بگیرد.
- تا زمان بررسی دقیق ساختار جداول و سیاست‌های RLS، داده‌های فروشگاه نمایشی هستند.
- این شاخه مستقل است؛ شاخه اصلی و نسخه منتشرشده دست‌نخورده می‌مانند.

## فناوری
React، Vite، Supabase JS، Lucide React
